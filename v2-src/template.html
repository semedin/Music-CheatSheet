02 / From browser to session

Five minutes in Ableton

  1. Export a clip or sketch. Drag the .mid file into Live.
  2. Load an instrument on each MIDI track. MIDI contains notes, not sound.
  3. Set your session tempo and check the clip’s loop bracket. Files end at the chosen bar length.
  4. Map the drum notes, choose a bass patch, then automate one sound parameter across eight bars.
